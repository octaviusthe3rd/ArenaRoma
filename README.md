# Arena Roma

Arena Roma is a 2D dark-fantasy arena shooter built in C# using MonoGame.

The player survives waves of enemies, dashes through danger, collects healing pickups, gains XP, levels up, and chooses upgrades that improve their chances of survival. The game uses a gothic gold-and-shadow visual style inspired by dark fantasy RPG interfaces.

## Features

- Wave-based arena combat
- Chaser enemies that pursue the player
- Shooter enemies that fire projectiles
- Mouse-aimed shooting
- Dash movement with invulnerability and damage
- XP and level progression
- Upgrade selection between levels
- Health pickups
- Combo-based score rewards
- Particle effects, explosions, screen shake, glow, and floating text
- Dark fantasy inspired HUD and menus

## Controls

| Action | Input |
|---|---|
| Move | WASD or Arrow Keys |
| Aim | Mouse |
| Shoot | Left Mouse Button |
| Dash | Space |
| Choose Upgrade | 1, 2, or 3 |
| Start Game | Enter |
| Restart After Death | R |
| Quit | Escape |
